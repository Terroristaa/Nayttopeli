# Näyttöpeli

Näyttöpeli on 2D-peli, jonka tein osana opintojani. Pelissä pelaaja liikkuu kentällä, taistelee vihollisia vastaan ja kerää tavaroita. Projekti on toteutettu Unityllä ja versiohallintaan käytettiin GitHubia.

---

## 🎮 Pelin ominaisuudet

- 2D top-down -liikkuminen
- Asejärjestelmä ja erilaiset hyökkäysanimaatiot
- Viholliset, joilla on oma liike- ja hyökkäyslogiikka
- Vihollisten kuolemisanimaatiot
- Tilemap-pohjainen kartta
- Äänitehosteet ja taustamusiikki
- Pelaajan statsit ja UI-elementit
